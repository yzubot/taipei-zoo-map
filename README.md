# 臺北市立動物園親子地圖

帶 2 歲小孩的手機優先地圖：官網遊園導覽圖疊在真實座標上＋GPS 定位＋設施搜尋（含別名、依距離排序）＋建議路線＋今日公休＋停車場即時空位。

- 設施座標：OpenStreetMap（Overpass 擷取館舍、廁所、餐廳、遊客列車站）
- 導覽圖：zoo.gov.taipei 園區地圖（已旋轉對位成北向 `zoo_map.png`）。對位用 12 個館舍／車站控制點做最小平方仿射，殘差 5–71 公尺（平均約 40 公尺），僅供參考
- 開放時間、公休表、遊客列車、餐飲、建議行程：官網
- 停車：臺北市停管處 TCMSV_allavailable.json（CORS 開放）
- 未做：data.taipei 動物/植物資料（無館舍級座標）、其他館的哺乳室座標（官網只標在服務中心）
- 純靜態頁，GitHub Pages 提供 https（瀏覽器定位需要 https）
